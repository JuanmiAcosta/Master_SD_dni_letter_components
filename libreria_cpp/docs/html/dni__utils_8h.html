Descripción detallada

API pública de la librería para calcular y validar el DNI español.

La letra de control se obtiene con el resto de dividir el número entre 23, usado como índice en la tabla oficial TRWAGMYFPDXBNJZSQVHLCKE.

Ejemplo de uso:

#include "dni_utils.h"
char letra = calcular_letra(12345678); // 'Z'
bool ok = validar_dni("12345678Z"); // true

◆ validar_dni()

bool validar_dni ( const char *  dni)

Comprueba si un DNI completo es válido.

Se aceptan exactamente 8 dígitos seguidos de una letra (mayúscula o minúscula). Se ignoran los espacios al principio y al final.

Parámetros
dniCadena terminada en nulo con el DNI, p. ej. "12345678Z". Puede ser nullptr.
Devuelve
true si el formato es correcto y la letra coincide; false en cualquier otro caso (nunca lanza excepciones).
