Ejercicio propuesto :

Diseñar, implementar y documentar tres componentes reutilizables que resuelvan la misma funcionalidad (calcular letra de un DNI español)

- Microservicio REST API en python
- Librería compartida en C++
- Librería en Java

Cada componenteb debe incluir :

- Código modular y reutilizable
- Especificación técnica de la API (OpenAPI, Doxygen y JavaDoc)
- Cliente que consuma el componente
- Documentación generada
